# 🎤 LyricView Pro

**LyricView Pro** is a modern church presentation software designed to display song lyrics, Bible verses, images, videos, and other presentation content during worship services.

Built with Python and PySide6, LyricView Pro provides a simple, reliable, and offline-friendly presentation experience for churches and worship teams.

From the original lightweight V1 release to the advanced **LyricView Pro X Studio**, the software has evolved to provide improved presentation tools, media support, remote control, and slide composition.

## 🚀 Installation Guide

### Step 1 — Download

Visit the repository's **Releases** page and download the installer for your preferred version.

Choose the latest available release if you want the newest features and improvements.

### Step 2 — Install

1. Locate the downloaded `.exe` installer.
2. Double-click the installer.
3. Follow the installation wizard.
4. Click **Install** and wait for the process to finish.
5. Launch LyricView Pro from the installed application or desktop shortcut, if available.

> Always download installers from the official repository or another authorized distribution source.

### Step 3 — Locate Your Data

LyricView Pro stores application data in the following directory:

```text
C:\Users\Public\Documents\livecore\
```

Depending on the version and enabled features, this directory may contain:

- Song databases
- Background images and videos
- Bible files
- Application data

**Important:** Back up your data folder before reinstalling, upgrading, or moving the application to another computer. Confirm the data directory used by your specific release before transferring files.

## ✨ Features

### 🎶 Song Lyrics Management
- Add, edit, and organize songs.
- Divide songs into multiple slides.
- Support sections such as Verse, Chorus, Bridge, and other song parts.
- Prepare lyrics for live worship presentations.

### 📖 Bible Integration
- Access Bible presentation features.
- Display Bible verses during services.
- Present verses with clean, projection-friendly formatting.

### 🎬 Multimedia Backgrounds
- Use image backgrounds.
- Play video backgrounds.
- Create visually engaging worship presentations.
- Use supported media playback components.

### 🖥️ Live Presentation Output
- Display presentations in fullscreen mode.
- Send content to an external display.
- Preview content before presenting.
- Use automatic text fitting for readable projection.

*Advanced output and multi-monitor capabilities depend on the selected version.*

### 📱 Mobile Remote Control
Control supported presentation functions using a phone's web browser.

Available controls may include:
- Next and Previous
- Go Live
- Black Screen
- Logo Toggle

The application can generate a QR code to help connect a mobile device.

**Connection requirements:**
- The computer and phone should be connected to the same Wi-Fi network.
- The application and remote-control server must be running.
- Firewall settings must allow the connection.

### 🎨 Modern Interface
- Dark-themed interface.
- Organized presentation controls.
- Dedicated editing workspace in Studio.
- Improved workflow for preparing and managing content.

### 🧩 Studio Slide Editor
Available in LyricView Pro X Studio.

- Compose slides using text, images, videos, and objects.
- Arrange presentation elements.
- Prepare reusable slide layouts.
- Save and reopen supported `.lvp` projects.
- Import PowerPoint presentations using the supported import feature.

### 💾 Offline-First Design
LyricView Pro is designed for reliable local use.

- Store supported application data locally.
- Use local databases and media files.
- Prepare presentations without requiring a constant internet connection.

Internet access may still be needed for downloading releases or using optional online services.
